# Simulador de movilidad — recogida de la tarde (Módulo 1)

App de Streamlit que modela la recogida de la tarde del colegio (motor SimPy).
Bilingüe (Español / English). Todas las cifras son ILUSTRATIVAS (datos
provisionales); leer dirección y orden de magnitud, no valores absolutos.
La seguridad es un límite infranqueable (descarte duro).

## Archivos
- `streamlit_app.py`  — interfaz (punto de entrada)
- `sim_app_core.py`   — réplicas / agregación / diagnóstico de régimen
- `afternoon_pickup_sim.py` — motor SimPy
- `i18n.py`           — textos ES/EN
- `requirements.txt`  — dependencias
